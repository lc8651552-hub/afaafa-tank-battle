# Tank Battle Web

A browser-based Canvas tank battle game. Open `index.html` to play.

## Controls

- Move with `WASD` or arrow keys
- Fire with the space bar
- Destroy enemy tanks to score points
- Protect the base; the game ends if the base is destroyed or lives run out

## Files

- `index.html` page structure
- `style.css` interface styling
- `game.js` game logic

## Deployment

This is a static web project and can be hosted directly on GitHub Pages, Netlify, or any static site service.
